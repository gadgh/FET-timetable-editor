# FET-timetable-editor

This project is a significantly modified and extended version of
[FET - edit + print](https://github.com/g-theodoroy/FET_edit-print),
originally created by George Theodoroy.

## About this version
I am a teacher working in a school unit and I use
[FET Free Timetabling Software](https://lalescu.ro/liviu/fet/)
for preparing the school timetable.

I found the original FET - edit + print tool particularly useful for
making necessary timetable changes after the timetable had been generated.

I have added and modified features that were useful for my own work,
and I am sharing this version in the hope that it may also help other
teachers and schools.

## Original project
- Original author: George Theodoroy
- Original repository: https://github.com/g-theodoroy/FET_edit-print
- Original file: `FET - edit + print.html`

The original project is described as being provided under the MIT License.
The original attribution has been retained.

## Main additions in this version
- teacher total-hours and contracted-hours columns
- teacher color management
- CSV export
- enhanced teacher and group schedule print views
- enhanced drag-and-drop conflict detection
- enhanced toolbar and day visibility controls
- additional timetable display improvements
